# Student Performance Analyzer

## 1. Project Title

**Student Performance Analyzer**

## 2. Project Overview

Student Performance Analyzer is a Python-based console application used to manage student records and analyze their academic performance. It allows users to enter student marks, calculate averages and grades, search records, and generate a class performance report. The project also includes an algorithm toolkit for practicing basic programming algorithms.

## 3. Features

* Add student records with name, roll number, and subject marks.
* Automatically calculate average marks and grades.
* View all student records.
* Search students by name or roll number.
* Generate class performance reports.
* Display class average, highest performer, pass count, and ranking.
* Validate user input and marks.
* Algorithm toolkit with:

  * Factorial
  * Fibonacci sequence
  * Reverse text
  * Decimal to binary
  * Exchange two values

## 4. Technologies / Tools Used

* **Python 3**
* Functions and loops
* Lists and dictionaries
* Conditional statements
* Exception handling
* Lambda functions
* Modular programming
* VS Code / PyCharm / IDLE

## 5. Project Structure

```text
Student Performance Analyzer/
│
├── main.py
├── student_module.py
├── report_module.py
├── algorithm_module.py
└── README.md
```

* **main.py** – Contains the main menu and controls the program.
* **student_module.py** – Handles adding, viewing, and searching students.
* **report_module.py** – Generates class performance reports and rankings.
* **algorithm_module.py** – Contains the basic algorithm toolkit.

## 6. Steps to Install & Run

1. Install **Python 3** on your computer.
2. Download or copy all project files into the same folder.
3. Open the project folder in a terminal or Python IDE.
4. Run the following command:

```bash
python main.py
```

5. Select an option from the main menu and follow the instructions.

## 7. Instructions for Testing

The following tests can be performed:

1. **Add Student:** Enter a student name, roll number, subjects, and marks.
2. **View Records:** Check whether the entered student details are displayed correctly.
3. **Search Student:** Search using the student's name or roll number.
4. **Performance Report:** Add multiple students and verify the class average, highest performer, pass count, and ranking.
5. **Input Validation:** Enter invalid values such as marks above `100` or below `0` and check that the program rejects them.
6. **Algorithm Toolkit:** Test factorial, Fibonacci, reverse text, decimal-to-binary conversion, and value exchange.
7. Select **0** to verify that the program exits correctly.
